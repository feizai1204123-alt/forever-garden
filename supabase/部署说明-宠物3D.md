## 第一步：运行 SQL（建表、限额、储存桶）

1. 用浏览器打开这个链接，会直接出现一个空白查询框：  
   https://supabase.com/dashboard/project/uxfyueebcughwaciqima/sql/new
2. 再打开这份文件，全选复制：  
   https://raw.githubusercontent.com/feizai1204123-alt/forever-garden/main/supabase/pet3d.sql
3. 粘贴到查询框里，点右下角绿色的 **Run**（或按 Ctrl+Enter）。
4. 成功时下方会显示类似 **Success. No rows returned**。

如果报错，把完整英文错误发我，我帮你改。

## 第二步：添加 Meshy 密钥（只加这一项）

1. 打开 Edge Functions 页面：  
   https://supabase.com/dashboard/project/uxfyueebcughwaciqima/functions
2. 找 **Secrets** / **密钥**（有的界面在页面上方，有的在左侧或「Manage secrets」）。
3. 新增一条：
   - Name（名字）：`MESHY_API_KEY`（必须一模一样）
   - Value（值）：你的 Meshy API Key（以 `msy_` 开头的那一串）
4. 保存。不要把 Key 发到聊天里。

`SUPABASE_URL` 和 `SUPABASE_SERVICE_ROLE_KEY` 平台会自动给函数，不用填，也不要发给我。

---

## 第三步：部署云函数 pet3d

1. 还是在这个页面：  
   https://supabase.com/dashboard/project/uxfyueebcughwaciqima/functions
2. 点 **Deploy a new function**（部署新函数），选择 **Via Editor**（通过编辑器）。
3. 函数名填：`pet3d`（必须是这 5 个字母，全小写）。
4. 把编辑器里的示例代码全部删掉。
5. 打开这份文件，全选复制，粘贴进去：  
   https://raw.githubusercontent.com/feizai1204123-alt/forever-garden/main/supabase/functions/pet3d/index.ts
6. 点 **Deploy function** / **部署**，等 10–30 秒，看到成功即可。
